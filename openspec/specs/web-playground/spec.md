## Requirements
### Requirement: Interactive Web Playground UI
The system SHALL provide a browser-based UI accessible locally for drag-and-drop screenshot testing.

#### Scenario: Drag screenshot to visually inspect bounding boxes
- **WHEN** a user uploads or drags a screenshot into the Web Playground
- **THEN** the page SHALL visually overlay detected YOLO/Contour bounding boxes and OCR text annotations in real time
